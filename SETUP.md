# Set up your coworker in your own Claude

About 10 minutes. You need a computer you use every day and a paid Claude plan.

1. **Get a Claude plan.** Your coworker runs on a paid Claude plan you buy from Anthropic at [claude.com/pricing](https://claude.com/pricing). Ouvrix never sells, holds or sees it.
2. **Install the desktop app.** Download it from [claude.com/download](https://claude.com/download), install it and sign in.
3. **Put this folder on your computer.** On this repository's GitHub page, press **Code**, then **Download ZIP**, and unzip it where you keep work files. If you use Git, clone it instead. If you downloaded a zip from ouvrix.com, unzip it there.
4. **Open the folder in Claude.** In the desktop app, start a Cowork task and choose this folder. Anthropic's guide: [Get started with Claude Cowork](https://support.claude.com/en/articles/13345190).
5. **Run the job once.** Open the file in `jobs/`, copy its prompt into the task and send it. Read what comes back.
6. **Schedule it.** When the first run looks right, ask Claude to run it on the schedule in the same file. Anthropic's guide: [Schedule recurring tasks in Claude Cowork](https://support.claude.com/en/articles/13854387).

Your coworker drafts and never sends. Read its note after each run, and send, pay or file things yourself.

Stuck? Anthropic's help center answers questions about the app: [support.claude.com](https://support.claude.com).
